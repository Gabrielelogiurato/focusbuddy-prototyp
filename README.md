# FocusBuddy – klickbarer Prototyp

Prototyp aus dem Design Sprint zum Modul 245 (Teil 2: Prototyping und Nutzertests).

**Live:** https://gabrielelogiurato.github.io/focusbuddy-prototyp/

## Worum es geht

FocusBuddy hilft Lernenden, mit einer Lernaufgabe anzufangen. Die App zerlegt eine
grosse Aufgabe in kleine Schritte mit realistischer Dauer. Gestartet wird immer nur
der erste Schritt.

## Was der Prototyp kann

- Aufgabe in drei vorgeschlagene Schritte zerlegt, eigene Schritte ergaenzbar
- Fokus-Session mit echt laufender Restzeit und Fortschrittsbalken
- Abbruch-Dialog mit zwei gleichwertigen Optionen
- Abschluss mit erledigten und offenen Schritten, Wochenuebersicht in Minuten
- Moderationspanel (Punkt unten rechts): misst die Sekunden bis zum Start,
  enthaelt die Testaufgaben und den Zuruecksetzen-Knopf

Kein Backend, keine Datenbank. Eine einzelne HTML-Datei.

## Lokal oeffnen

`index.html` doppelklicken. Funktioniert ohne Server und ohne Internet.
